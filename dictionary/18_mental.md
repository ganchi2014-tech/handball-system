# メンタルマネジメント・自己診断

> 試合中の不安・緊張・ミス後の立て直し。ノルウェー語のメンタル5概念を核に構成。
>
> **このファイルの読み方**：心の整え方は人によって合う・合わないがある。ここにあるのは「方法の種類」で、正解ではない。
> 部のメンタルトレーニングの枠は「最適な緊張感は人によって違う（覚醒型・落ち着き型・間の型）。自分に合った方法で向き合う」。
> 出どころの書き方：〔教材〕＝ノルウェー協会などの教材／〔まとめ〕＝AIが一般的な方法を整理したもの／〔未確認〕＝根拠を確かめられていないもの。

---

## メンタルの5要素（ノルウェー語 NHF原典）

| ノルウェー語 | 日本語 | 内容 |
|---|---|---|
| **メストリング（達成感）** | 習得・達成感 | 「できた」という実感がモチベーションの源泉 |
| **セルヴティリット（自信）** | 自信 | DFに仕掛ける・GKが飛び込む判断力の基盤 |
| **ヴィスアリセーリング（視覚化）** | イメージトレーニング | プレー前に成功シーンを頭の中で描く |
| **インドレ・ディアログ（内的対話）** | 内的対話（セルフトーク） | 「できる」「次はこうする」の自己言語化 |
| **トリッゲレ（誘発する）** | メンタルトリガー | 集中を高める特定の合図・ルーティン |

## 試合前のメンタル準備

### ヴィスアリセーリング（視覚化）（イメージトレーニング）

```
試合の前夜・当日朝・ウォーミングアップ中に行う

① 自分が成功するシーンを具体的に描く
   例：「右バックから廻旋フェイント → 内突破 → ループシュートが決まる」
② 視覚だけでなく、聴覚（声援・ボールの音）・触覚（ボールの感触）も含める
```

**描く中身は2通りある**〔まとめ〕

| 描き方 | やること | 起きやすいこと |
|---|---|---|
| うまくいく場面を描く | 決まる場面を動き・感覚まで細かく思い浮かべる | 動きの手順が整理される。思いどおりにいかなかったときの次の手は入らない |
| 起こりうる失敗を先に並べる | 止められる・読まれる場面を並べ、そのとき何をするかまで決めておく | 止められた後の次の手が先に入る。並べるだけで対応を決めないと不安だけが残る |

どちらが合うかは人による。両方やる人もいる。
「失敗を思い描くと失敗が体に刷り込まれる」と言われることがあるが、根拠は確かめられていない〔未確認〕。

**補足**：イメージトレーニングを習慣にしている一流選手は多いと言われる（具体的な割合の出どころは確かめられていない）〔未確認〕。
ただし**具体性が低いイメージ**（「頑張る」「勝つ」）は効果薄い。**動作・感覚レベルの具体性**が必要。

---

### トリッゲレ（誘発する）（メンタルトリガー）の作り方

```
試合前・プレー前に「集中スイッチを入れる」自分だけの合図

例：
- ボールを持つ前に右手でボールを2回叩く
- フリースロー前に深呼吸を3回
- タイムアウト後に味方とハイタッチ
- ベンチに座るときに右足から座る

ポイント：同じ動作を毎回繰り返す
→ パブロフ的条件反射（毎回同じ刺激を繰り返すと体が自動で反応するようになる仕組み）で「この動作 = 集中モード」が脳に刷り込まれる
```

**注意**：迷信的になりすぎない（「やらないと負ける」と思うとプレッシャーが増える）。

## 試合中のメンタル管理

### ミス直後の立て直し（3秒ルール）

ミスの直後の扱い方は2通りある〔まとめ〕。

| 扱い方 | やること | 起きること |
|---|---|---|
| すぐ切り替える（下の3秒ルール） | 次にやることを一言決めて前のプレーを離す | 引きずりにくい。なぜ止められたかは残らない |
| 短く振り返って組み替える | 「相手は何をしてきたか」を一つ確かめ、次の手を入れ替える | 同じ相手に同じ手で臨まなくなる。長くなると次のプレーに遅れる |

場面にもよる（守りに戻る最中は切り替え、次の攻撃までの間は振り返り、など）。以下は「すぐ切り替える」方法の手順。

```
ミスした瞬間：
0〜1秒：自分のミスを認識する（隠さない・否定しない）
1〜2秒：インドレ・ディアログ（内的対話）で「次は○○する」と言う
       NG：「あー」「最悪」（過去を引きずる）
       OK：「次はピボットを見る」（未来に向ける）
2〜3秒：トリッゲレ（誘発する）発動（深呼吸・小さなジェスチャー）→ 集中再起動
3秒以降：次のプレーへ完全に切り替え
```

**長く引きずるミス vs すぐに切り替えるミス**：
- 引きずる選手：1つのミスから3〜5プレー連続でミスが続く（メンタル連鎖）
- 切り替える選手：次のプレーで小さな成功 → メストリング（達成感）→ セルヴティリット（自信）回復

### プレッシャー下の集中

**プレッシャーが高い状況の典型**：
- 残り2分・1点差
- 7m投擲（反則で与えられる、GKと1対1で打つペナルティスロー）
- タイムアウト後の1本目
- 5連続失点で味方が崩れている
- 大事な試合の開始時（自分への期待）

**プレッシャー下の認知低下**：
- 視野が狭くなる（中央集中視野＝正面の一点ばかり見て、左右の味方やスペースが見えなくなる状態）
- 判断時間が長くなる（情報処理が遅れる）
- 体が硬くなる（フェイントが効かない）

**向き合い方の種類**〔まとめ〕（どれが合うかは、自分の最適な緊張感がどの型かで変わる）：

| 型 | 方法の例 | 起きること |
|---|---|---|
| 落ち着かせる | 深く吐く呼吸を数回 | 副交感神経（体をリラックスさせる神経）が働き心拍数が下がる。高ぶっているほうが動ける人は、下げすぎると動きが鈍る |
| 上げる | 声を出す・速い足踏みやジャンプ・テンポの速い曲 | 体と気持ちが起きる。上がりすぎると視野が狭くなる |
| 間を取る | 決まった動作を一つ挟む（トリッゲレ） | 緊張の強さは変えずに、いつもの状態に戻る合図になる |

**どの型でも使える見方**：
```
・視野を意識的に広げる（周辺視野を取り戻す）
・選択肢を絞る：絞ると判断は速くなる。そのぶん相手には読まれやすくなる。
  いくつ持ったまま動けるかは、その場面の準備（事前に相手のパターンを入れているか）で変わる
・インドレ・ディアログ（内的対話）を使う：「やれることをやる」「次の1プレーだけ」
```

### 接戦終盤の心理

**「終盤崩れ型」選手の特徴**：
- 残り時間ばかり気にする
- スコアボードを何度も見る
- 過去のプレーを後悔する
- 「今打たないと」という焦り

**「終盤強い」選手の特徴**：
- 「次の1プレー」だけに集中
- 残り時間を見ない（味方やコーチに任せる）
- ミスをすぐ手放す
- 「自分のシュート」を信じる（セルヴティリット（自信））

## メンタル状態の自己診断

### 試合中の自分の状態をチェック

```
Q1: 今、視野は広いか？
  Yes → 集中できている
  No  → プレッシャーで狭くなっている → 自分の型に合った方法（落ち着かせる／上げる／間を取る）・視野広げる

Q2: 判断は速くなっているか？
  Yes → リズムに乗れている
  No  → 考えすぎ → 第一選択を即実行する意識

Q3: ミスを引きずっているか？
  Yes → 3秒ルールを思い出す・トリッゲレ（誘発する）発動
  No  → 集中継続

Q4: 体は硬いか？
  Yes → ジャンプ・スキップで体ほぐす
  No  → 良好

Q5: 自信はあるか？
  Yes → 仕掛ける勇気あり
  No  → メストリング（達成感）（小さな成功）を作る：簡単なパスから始める
```

## 自分のレベル診断（技術・戦術・メンタル3軸）

### 技術レベル診断

```
【シュート】
□ レベル1: ジャンプシュートが安定して打てる
□ レベル2: 早打ち・最高点・下降中の打点を使い分けられる
□ レベル3: バックハンドフェイク・回転シュートが試合で使える
□ レベル4: GKタイプを見抜いて最適な打点・コースを選べる

【フェイント】
□ レベル1: 1〜2種類のフェイントを試合で使える
□ レベル2: 3〜5種類のフェイントを場面で使い分けられる
□ レベル3: ダブルフェイント原則（2種連続）・廻旋フェイントを実戦で使える
□ レベル4: DFの「何を見ているか」を読んで対応フェイントを選べる

【パス・ドリブル】
□ レベル1: 両手キャッチが安定。ワンハンドキャッチも可
□ レベル2: バウンスパス・ロブパス・ノールックパスが使える
□ レベル3: ドリブル中のフェイント（ジャブ・ヘジテーション等）が使える
□ レベル4: 受ける前の勝ち位置取りが意識せずできる
```

### 戦術レベル診断

```
【DF読み】
□ レベル1: クローズ/ワイドの違いがわかる
□ レベル2: 0-6/5-1/マンツーマンを見分けられる
□ レベル3: フェアシーベン（シフト）/ヘラウスリュッケン（前飛び出し）/ユーバーゲーベン（引き渡し）の動きを読める
□ レベル4: DFタイプから最適なOFアクションを選べる

【GK読み】
□ レベル1: GKが動くか動かないかを観察できる
□ レベル2: 先読み型/コース絞り型を見分けられる
□ レベル3: GKタイプから打点・コースを選べる
□ レベル4: 試合中にGKタイプの変化を読み取って対応できる

【連携】
□ レベル1: ピボットへのパスが出せる
□ レベル2: ギブ&ゴー・ピック&ロールが使える
□ レベル3: クロス・3人ウェーブ等のコンビネーションが使える
□ レベル4: チームのOFタイプを理解して自分の役割を果たせる
```

### メンタルレベル診断

```
【プレッシャー耐性】
□ レベル1: 普通の場面で集中できる
□ レベル2: ミス後3秒で切り替えられる
□ レベル3: 接戦終盤でも視野が狭くならない
□ レベル4: プレッシャーをむしろ集中の源にできる

【ルーティン】
□ レベル1: トリッゲレ（誘発する）を持っている（特定の合図）
□ レベル2: ヴィスアリセーリング（視覚化）を試合前に行う
□ レベル3: インドレ・ディアログ（内的対話）でセルフトークを使える
□ レベル4: メストリング（達成感）→ セルヴティリット（自信）の循環を意識して作れる
```

## メンタルじゃんけん

```
プレッシャー高い
  → 視野狭くなる・判断遅れる
  → 自分の型に合った方法で向き合う（落ち着かせる／上げる／間を取る）
  → 成功 → メストリング（達成感） → セルヴティリット（自信）回復
  → 余裕が出る → プレッシャー耐性アップ

ミスする
  → 3秒以内に切り替え
  → インドレ・ディアログ（内的対話）「次は○○」
  → 次のプレーで小さな成功
  → メストリング（達成感）回復
  → ミス連鎖を断ち切れる

接戦終盤
  → 残り時間気になる
  → 「次の1プレーだけ」に意識を絞る
  → ミスしても引きずらない
  → 終盤強い選手になる
```

## 【なぜフィジカルが必要か】バックプレーヤーの試合負荷データ

```
研究（PMC 2023, Physical Demands during Official Competitions in Elite ハンドボール）

バックプレーヤーの1試合平均走行距離：約4.96 km
  ※ウィング（4.23 km）・ピボット（3.91 km）より多く、全ポジション中最長

高速走行（High-speed running=ある速度以上の速い走り）距離：センターバック平均 243.2 m/試合
スプリント距離（全力疾走＝高速走行よりさらに速い走り）：センターバック平均 62.0 m/試合
試合中の心拍数：HRmax（最大心拍数=その人が出せる心拍数の上限）の85〜90%で推移（ほぼ全力に近い強度）

→ バックプレーヤーは全ポジション中、最も体力資源を消費するポジション。
→ 投擲能力（シュート速度）と跳躍能力の両立が最重要要件。
```

## 【A】主要筋群と役割（なぜその筋肉か）

### A-1. 上半身

| 筋群（日本語） | 原語 | ハンドボールとの関連 |
|---|---|---|
| 回旋筋腱板（棘上筋・棘下筋・小円筋・肩甲下筋） | Rotator Cuff | シュート動作の減速制御。多数の投擲に耐える肩の土台 |
| 三角筋 | Deltoid | オーバーハンドスローの推進力 |
| 前鋸筋 | Serratus Anterior | スロー時の肩甲骨安定化 |
| 僧帽筋下部 | Trapezius Lower | 投球肩（Thrower's ショルダー）予防に不可欠 |
| 広背筋 | Latissimus Dorsi | 腕の加速・減速の両方に関与 |
| 腹斜筋 | Obliques | 体幹回旋→サイドアームシュートの動力源 |
| 体幹（インナーマッスル） | コア / Rumpfstabilität | 下半身の爆発力を上半身へ伝達する連結部 |

### A-2. 下半身

| 筋群（日本語） | 原語 | ハンドボールとの関連 |
|---|---|---|
| 大臀筋・中臀筋 | Gluteus Maximus/Medius | 踏み切り・方向転換・ランジの主動力 |
| 大腿四頭筋 | Quadriceps | ジャンプシュートの離地力 |
| ハムストリングス | ハムストリングs | スプリント加速・着地衝撃吸収。ノルディックで損傷が減ると言われる〔未確認〕 |
| 腸腰筋 | Hip Flexors | 跳躍後の着地コントロール・走フォーム |
| 内転筋群 | アダクター（内転筋） | 横方向の急停止・サイドステップ安定 |
| 下腿三頭筋 | Gastrocnemius/Soleus | 踏み切り・スタートダッシュ |

## 【B】筋力トレーニング（爆発力training / Maximalkrafttraining）

> **読み方**：ここにあるのはドイツ協会などの資料にある方法と数字の紹介で、部の計画ではない。
> やるか・どの方法で・どの強さと回数でやるかは自分で決める。目安として使う。
> 方法の種類：自重（腕立て・スクワット・懸垂・体幹など。器具なしでできる）／バーベルやダンベル／ジャンプ系／メディシンボール。

### 基本方針

```
研究エビデンス：
ベンチプレス1RM（最大1回挙上重量）とシュート速度の相関係数 r = .637（1.0に近いほど強い関係。0.6超は「かなり強い関係」で、偶然ではないと統計的に確認された）
→ 上半身の筋力とシュート速度には関係があると言われる（関係があることと、鍛えれば必ず速くなることは別）

教材に載っている強度の目安（高重量は正しいフォームを身につけてから、指導者のいる所で行う。部の計画ではない）：
  最大筋力期（Maximalkraft） → 85〜95% 1RM
  爆発力期（爆発力）   → 60〜80% 1RM（最大重量の6〜8割。軽めにして最大速度で素早く挙げ、速さを鍛える）
```

### ハンドボール特化種目（ハンドボール-specific exercises）

```
ケーブルウッドチョップ（Cable Woodchop）
  → 斜め上から斜め下へ。腹斜筋・体幹回旋。シュート動作と直結。

サイドランジ（Side Lunge）
  → 内転筋・大臀筋。横方向の急停止動作に直結。

ゴブレットスクワット（Goblet スクワット）
  → 体幹と下肢の協調。方向転換前の準備姿勢。

ラテラルバンドウォーク（ラテラル（側方） バンド Walk）
  → 中臀筋強化。膝・股関節外側安定化。足首捻挫予防にも。

ワンアームランドマインプレス（One-arm Landmine Press）
  → 片手プレス・回旋安定性。実際の投擲動作に近い。
```

## 【C】ジャンプトレーニング（プライオメトリクス / Sprungkrafttraining）

### 研究エビデンス

```
PMC 2023（ユース女子ハンドボール・10週間・週2回）：
  SJ（しゃがんだ姿勢で静止してから跳ぶ＝反動なし跳び）・CMJ（一度しゃがむ反動を使って跳ぶ＝反動あり跳び）・立ち幅跳びが有意改善

メタアナリシス（エリートハンドボール選手）：
  SJ 改善率：4.5〜13.9%
  CMJ 改善率：5.7〜11.4%

複合プログラム（筋力＋プライオメトリクス 12週間）：
  SJ +6.1%、CMJ +3.8%、連続40回ジャンプ +6.8%
```

### テスト種目

| テスト名 | 略称 | 内容 |
|---|---|---|
| スクワット Jump | SJ | 反動なし垂直跳び（爆発的同心収縮） |
| Countermovement Jump | CMJ | 反動あり垂直跳び（SSC＝伸ばした筋肉をすぐ縮める反動動作を使う） |
| CMJ with Arms | CMJA | 腕振り反動ありCMJ |
| Standing Long Jump | SLJ | 立ち幅跳び |
| Drop Jump | DJ | 台上からの落下→反動跳び（衝撃吸収＋爆発力） |

### プライオメトリクス種目（レベル別）

```
基礎レベル（Grundstufe）：
  ボックスジャンプ / スクワットジャンプ / 幅跳び / スキッピング

中級レベル（Aufbaustufe）：
  ドロップジャンプ / ラテラルバウンド（横跳び） / 片脚CMJ / ディプスジャンプ

上級レベル（Hochleistungsstufe）：
  ボール操作を含む反応跳躍 / ジャンプ中のメディシンボール投げ / ハードルホップ
```

**注：** CMJ（しゃがむ反動を使う跳び＝遅いSSC）はSJ（縮む力だけで跳ぶ＝同心収縮のみ）より高いトレーニング効果を得やすい

## 【D】スピード・アジリティ（Schnelligkeit / アジリティ（敏捷性））

### ハンドボール特化型ドリル

**Tテスト（T-Test アジリティ（敏捷性））**
```
設定：コーンをT字型に配置（縦10m・横各5m）
実施：前方10mダッシュ → 左5mサイドシャッフル → 右10mシャッフル → 左5mシャッフル → バックペダルでスタートへ
基準：男性 9.5秒未満 = 優秀〔未確認〕
```

**プロアジリティ（Pro アジリティ（敏捷性） / 5-10-5 Shuttle）**
```
設定：3点コーン（各4.5m）
実施：中央スタート → 右4.5m → 左9m → 中央4.5m
目的：短距離での最大加速・急停止・切り返し
```

**コート特化型スプリント**
```
シャトルスプリント：6mライン〜センター往復（2×15m）
バックプレーヤー特化：25m往復ダッシュ（長い距離より短距離が試合に即している）
バック＆フォース：ゴール〜センターの前後ダッシュ繰り返し
```

**ラテラルバウンド（ラテラル（側方） Bounds / Skate Jumps）**
```
横方向への単脚跳躍繰り返し
→ サイドステップの爆発的パワー。コートカバーに直結。
```

## 【E】持久力トレーニング（持久力 / Endurance）

### ハンドボールの持久力特性

```
試合時間：60分（前後半各30分）
試合中平均心拍数：HRmax の85〜90%
バックプレーヤー：高強度活動の割合が全ポジション中最多

有酸素能力の目標値（男子エリート）：VO₂max（最大酸素摂取量＝1分間に体重1kgあたり取り込める酸素量で持久力の指標）50〜60 ml/kg/min
```

### HIIT プロトコル（例3種類）

**タイプ A：4×4分（ハンドボール最多使用）**
```
内容：4分間 HRmax の90〜95%強度 → 4分アクティブリカバリー（60〜65%）
セット：4セット
頻度：研究では週2回を8〜12週間続けた例が多い（部の計画ではない）
根拠：ハンドボール選手のVO₂max改善に最も高いエビデンス（系統的レビュー 2024）
```

**タイプ B：短インターバル（EHF推奨・試合特異性が高い）**
```
内容：10秒間 最大速度の95%で走行 → 20秒リカバリー
セット：2セット × 22本
特徴：ハンドボールの動作パターン（短い爆発＋短い回復）に最も近い
```

**タイプ C：長インターバル（有酸素容量構築）**
```
内容：3分間 最大速度の85% → 3分リカバリー
セット：5セット
特徴：有酸素ベースの構築に有効
```

**スモールサイドゲーム（Small-Sided Games / SSG）**
```
少人数・狭コートでのゲーム形式
効果：持久力・技術・戦術を同時に鍛えられる
研究：SSGグループはTテスト・シュート速度・Yo-Yoテストで有意改善
実践：スペイン・スカンジナビアのクラブで有酸素トレーニングの主要代替手段として使用
```

**Yo-Yo インターミッテントリカバリーテスト（YYIRT1）**
```
正式名：Yo-Yo Intermittent Recovery Test Level 1
内容：20mシャトルランを漸増速度で実施。各ラン後10秒アクティブリカバリー
用途：ハンドボール選手の持久力評価の標準テスト
```

## 【F】年齢別指針（DHB 運動能力づくりの考え方 2024 / Rahmentrainingskonzeption）

### DHBの長期育成5段階（Langfristiger Leistungsaufbau）

| 段階 | ドイツ語名 | 対象年齢 | 主な内容 |
|---|---|---|---|
| 1 | Grundlagenschulung（基礎教育） | ～12歳 | 多様な動作・楽しさ優先 |
| 2 | Grundlagentraining（基礎トレーニング） | 12〜14歳 | 協調性・自体重・体幹安定 |
| 3 | アウフバウトレーニング第1段階（発展I） | 14〜16歳 | 外部負荷導入（砂袋・ケトルベル） |
| 4 | アウフバウトレーニング第2段階（発展II） | 16〜18歳 | バーベル筋力・爆発力の系統的発達 |
| 5 | アンシュルストレーニング（接続練習） | 19歳〜 | 競技特化・個人特化 |

### 高校生（16〜18歳 / アウフバウトレーニング第2段階）の具体的指針

```
ドイツの教材の目安：週2〜3回、1回30〜45分（部の計画ではない。回数や時間は部の予定に合わせる）
毎練習前にアスレチックウォームアップ（15分）
バーベル筋力トレーニングの本格導入
爆発力とMaximalkraft（最大筋力）の両方を系統的に訓練
固有受容感覚トレーニング（バランスボード等）の導入

ノルウェー研究（PMC 2021・15〜18歳・205名）による警告：
  週6回以上のセッションは過負荷リスクあり
  週間傷害発生率 53%、重篤な怪我の割合 38%
  → RPEスケール（自分のきつさを0〜10で点数化する主観的運動強度の指標）を使用し、週sRPE（1回の練習のきつさ点数×練習時間を1週間ぶん合計した値。単位AU）を1,000〜1,400 AU以内に抑える
```

## 【G】ピリオダイゼーション（Periodisierung / 周期計画）

> 資料にある考え方の紹介。「試合の前後で負荷を変える」という見方を知るためのもので、部の予定表ではない。

### シーズン区分と重点

| 期間 | ドイツ語 | 主な目標 | 内容 |
|---|---|---|---|
| プレシーズン（6〜8週） | Vorbereitungsphase | 体力基盤構築 | 高volume筋力・有酸素基盤 |
| インシーズン（競技期） | Wettkampfphase | 試合パフォーマンス維持 | 週2回の維持筋力・SSG型有酸素 |
| オフシーズン（移行期） | 切り替えsphase | 回復と再構築 | アクティブリカバリー・有酸素ベース |

### 週間サイクル例（試合1回/週）

| 曜日 | 内容 | 負荷 |
|---|---|---|
| 試合翌日（MD+1） | アクティブリカバリー（軽い有酸素） | 低 |
| MD+2 | 筋力トレーニング（高負荷） | 高 |
| MD+3 | テクニカル・タクティカル＋SSG | 中 |
| MD-3 | 筋力（維持目的・低volume） | 中 |
| MD-2 | スピード・アジリティ | 中 |
| MD-1 | 軽い技術練習・活性化 | 低 |
| 試合当日 | 試合 | 最高 |

## 【H】ケガ予防プログラム（Verletzungsprävention）

### ハンドボール主要傷害部位

```
全傷害の約50%が膝・足首に集中
バックプレーヤーは肩の過負荷傷害（オーバーユース）が最多

Thrower's ショルダー（投球肩）：
  内旋制限GIRD（肩を内向きにひねる可動域が狭くなる状態。Glenohumeral Internal Rotation Deficit）
  ＋外旋過剰（外向きにひねる動きが過剰）の組み合わせで発症
```

### 予防エクササイズ

**肩（Schulter / ショルダー）：**
```
外旋運動（エクスターナル ローテーション in 90° アブダクション（外転））
  → 90°外転位（腕を真横に90度上げた姿勢）で内旋・外旋。回旋筋腱板強化。

Yレイズ（Y Raise）
  → 下部僧帽筋・回旋筋腱板・肩甲骨安定筋群。

バンド外旋（バンド エクスターナル ローテーション）
  → 低負荷・高反復。毎日実施可能。

研究（フロンティアズ（学術誌） 2024）：
  6週間の等速性偏心外旋訓練で肩の柔軟性・筋構造が有意改善
  （男子ジュニアハンドボール選手対象）
```

**膝・ハムストリングス：**
```
ノルディックハムストリング（ノルディック・ハムストリング Exercise / NHE）
  → 週1〜2回・20週間継続で大腿二頭筋の損傷が減ったという研究があると言われる〔未確認〕
  → 高校生に特に推奨

片脚スクワット（Single-leg スクワット）
  → 膝関節アライメント強化
```

**足首（Sprunggelenk / アンクル（足首））：**
```
バランスボードトレーニング
  → 固有受容感覚（Propriozeption）強化

ラテラルバンドウォーク
  → 中臀筋強化→下肢アライメント安定→捻挫予防
```
